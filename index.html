07

Multilingual Enforcement Consistency

Model evaluation · Multilingual safety · Python
A usage policy says nothing about language. The model shouldn't either — but it does. Safety that holds in English does not always survive translation, and an English-only eval is structurally blind to it.

Takes the policy-to-decision taxonomy from project 03 and adds one variable: the language a request arrives in. Thirty borderline prompts, hand-translated into English, Chinese, French, Singlish and Singapore Mandarin — with the SEA scam typologies, care-system vocabulary and racial-harmony framing that only exist in-language — then measured for whether the same request gets the same decision.

08

Distress-Conversation Safety Eval

Model evaluation · Multi-turn safety · Python
The second-highest scoring system in the suite is the one that must not ship. It holds its boundary for five turns, then concedes from turn six under a claimed clinical credential.

A rubric-based harness for multi-turn conversations with escalating user distress. It measures the failure single-turn evaluation structurally cannot see: a system that refuses correctly on turn one and concedes on turn nine. Criteria are operationalised from Samaritans, WHO and NICE NG225 guidance, with provenance recorded per criterion in code.
